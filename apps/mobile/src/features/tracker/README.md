# Трекер тренировок

Запись тренировки в приложении: подготовка → отсчёт → запись → итог → экран тренировки с комментарием Трефа.

## Входы

- **«Начать тренировку»** на Today (`RecordButton`) — подготовка. Если на сегодня есть незавершённая тренировка, она выбрана по умолчанию (вкладки «По плану / Свободная»), иначе свободная со строкой «Цель».
- **Шторка цели** на Today (`main/components/today/workout-goal-sheet.tsx`, плитки типа и «+» в шапке). Режим — по выбранному в календаре дню: сегодня — цель + «Начать сейчас» / «Добавить»; будущий день — «Добавить»; прошедший — «Как прошло» и сохранение выполненной.
- **Экран тренировки**: начать можно только в день тренировки; будущую или пропущенную свою тренировку можно «Перенести на сегодня».

## Цель

Своя тренировка хранит одну цель: `target.goal = none | duration | distance` (+ `timeLimitMin` для дистанции). Вторая величина не придумывается: в колонке остаётся 0, в шторке она только показывается как оценка (`main/lib/goal-estimate.ts`). Цель выполняется как один шаг плана (`run-goal.ts`, на сервере — `WorkoutExecutionBuilder`): время — шаг по времени, дистанция — шаг по дистанции, ограничение по времени даёт коридор темпа ±5 с.

## Подготовка

GPS включается сам, если есть доступ к геопозиции; без доступа запись идёт по шагомеру (плашка с переходом в настройки, кнопка «Старт по времени»). Перед системным запросом показывается экран «Доступы» (`components/access-screen.tsx`). На дорожке автопауза по умолчанию выключена. Голосовые подсказки — шторка `components/voice-sheet.tsx` (частота и состав отчёта, `VoiceSettings.report`).

## Запись

Страницы: показатели (свободная — дистанция и 4 ячейки, ячейка меняется долгим нажатием, набор хранится в `AsyncStorage`), карта (только с GPS в нативной сборке), шаги плана. Карточки: план (`PlanCard`, после шага — `StepDoneCard` на 3 с), цель по времени, дистанция за время (коридор, опережение/отставание, прогноз). Пауза — «Завершить» удержанием; запись короче 200 м и 1 мин не сохраняется. Если приложение закрылось во время записи, на Today появляется шторка «Запись прервалась».

## Итог

Результат, план и факт, сплиты, «Как прошло?», данные (тип, дистанция — правка шторкой, кроссовки), сохранение в Health. Свободная запись в день с незавершённой тренировкой по умолчанию засчитывается как она (переключатель; выключенный отправляет `linkPlanned: false`). После «Сохранить» открывается экран тренировки.

## Карты

Mapbox Standard (`lightPreset` day/night по теме, без POI и транспорта). В Expo Go карт нет — вместо них заглушка.
